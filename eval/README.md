# Evaluation

How the numbers in the main README were produced, so anyone can reproduce them.

- **Data:** where it comes from, its license, and how to download it (no private data).
- **Metrics:** exact definitions (for example WER, p95 latency, cost per minute).
- **Hardware:** the machine or device used.
- **Run:** `python eval/run_eval.py`
- **Baselines:** what you compared against, with versions.
